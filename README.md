
# Zamtel Loans Zambia

A mobile-friendly loan application interface prototype designed for Zambia, using Zamtel-inspired red and white styling.

## Features

- Loan amount slider in Zambian Kwacha (ZMW)
- Separate application pages
- Zambian phone number input
- Simulated OTP verification
- Test-only PIN step
- Full name and email fields
- Application progress indicator
- Responsive mobile layout
- Application completion screen

## Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

## Run Locally

Install Node.js, then run:

```bash
npm install
npm start
```

Open the local address displayed by the server in your browser.

## Deploy on Render

1. Push this project to GitHub.
2. Create a new Web Service on Render.
3. Connect your repository.
4. Set the build command to:

   `npm install`

5. Set the start command to:

   `npm start`

6. Deploy the service.
